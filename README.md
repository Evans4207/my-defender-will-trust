# My Defender Will & Trust

Self-help platform for creating a state-compliant Last Will & Testament or
Revocable Living Trust, with a durable financial power of attorney, healthcare
directive and HIPAA authorisation. Private repository — not publicly indexed, no
live payments taken.

---

## 👋 Reviewing this for legal sign-off? Start here.

**You do not need to download anything, and you do not need to read any code.**

| | |
|---|---|
| **1. What we are asking you to decide** | **[Legal Review Checklist](docs/LEGAL_REVIEW_CHECKLIST.md)** — reads in your browser. Its first page is written in plain English. |
| **2. Working state by state** | **[State-by-state review index](docs/STATE_REVIEW_INDEX.md)** — all 51 jurisdictions, each with a **live link to that state's own official statute**, what we captured, and the wording we produced. |
| **3. Prefer to annotate in Word** | [Download the .docx](docs/LEGAL_REVIEW_CHECKLIST.docx) — the canonical version. The page above is the same document, rendered for reading. |

**The short version.** Every generated document currently carries placeholder
text marked `[ATTORNEY REVIEW REQUIRED]`, and all 51 jurisdictions are flagged
`needs_review = true`. Nothing is sold in any state until you approve that state.
On the wording that matters most — the self-proving affidavit — **34 states**
reproduce that state's own official form word for word and need confirming;
**8 states** carry a draft we wrote because the statute prescribes no form, and
need correcting; **9 jurisdictions** are open questions, 5 of which need
something from you we cannot obtain ourselves.

We are a product team, not lawyers. None of this has been legally reviewed — it
is desk research, done so that you review a draft rather than build one.
